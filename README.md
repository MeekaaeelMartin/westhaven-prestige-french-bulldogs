# Westhaven French Bulldogs

Static 4-page website for **Westhaven** (Katrina & Colton West).

## Pages

- `index.html` — Home
- `about.html` — About
- `dogs.html` — Dogs, current litter & previous litter
- `contact.html` — Contact

## Local preview

```bash
npx serve .
```

## Deploy

```bash
npm run deploy
```
